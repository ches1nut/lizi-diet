# 健身饮食规划 WebApp（Fit Diet）

一个纯前端、零依赖的健身饮食规划工具。本地双击 `index.html` 即可使用。

## 功能

- **方案库（7 个）**：三个月减脂、三倍碳水、碳水渐降、532 碳水渐降、凯圣王碳循环、中国居民膳食指南、增肌盈余法
- **方案选择**：按目标（增肌/减脂/日常健康）筛选、查看详情、勾选最多 3 个方案横向对比
- **问卷推荐**：回答目标 + 个人信息 + 专属分支问题，自动推荐最匹配的方案
- **营养计算**：输入个人信息，计算 BMR、TDEE、目标热量与三大营养素克数
- **推荐食谱**：匹配方案后，按目标从内置餐食模板库配好一日三餐，按体重缩放，可手动增删菜品
- **食物热量计算**：搜索/分类选食物 + 输入克数累加算热量；拍照/上传图片存档（暂不自动识别）；支持手动新增自定义食物
- **我的面板**：本地保存个人信息与「当前选择方案」，首页快捷入口

## 计算依据（均有文献出处）

- 基础代谢：**Mifflin-St Jeor 公式**（Mifflin et al., *Am J Clin Nutr* 1990; 51(2):241-247）
- 蛋白质：**ISSN 2017 立场声明**（增肌 1.6–2.0 g/kg，减脂期可达 2.3–3.1 g/kg）
- 碳水供能比：**中国卫健委《中国居民膳食指南》**（增肌期 60–65%，约 4–6 g/kg）
- 增肌热量盈余：**ISSN 2017**（300–500 大卡/天）
- 活动系数：**FAO/WHO/UNU 2001** PAL 分级（1.2–1.9）

## 使用方式

直接用浏览器打开 `index.html`，或在本地起一个静态服务器：

```bash
# Python
python3 -m http.server 8000
# 然后访问 http://localhost:8000
```
