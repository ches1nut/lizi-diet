# 健身饮食规划 WebApp（Fit Diet）

一个纯前端、零依赖的健身饮食规划工具。本地双击 `index.html` 即可使用。

## 功能

- **计算营养需求**：输入性别/年龄/身高/体重/活动量/目标，计算 BMR、TDEE、目标热量与三大营养素克数
- **食物热量库**：内置常见食物（`foods.js`），支持分类筛选与搜索
- **生成食谱**：根据目标热量自动搭配三餐

## 计算依据（均有文献出处）

- 基础代谢：**Mifflin-St Jeor 公式**（Mifflin et al., *Am J Clin Nutr* 1990; 51(2):241-247）
- 蛋白质：**ISSN 2017 立场声明**（增肌 1.6–2.2 g/kg，减脂期可达 2.3–3.1 g/kg）
- 活动系数：**FAO/WHO/UNU 2001** PAL 分级（1.2–1.9）

## 使用方式

直接用浏览器打开 `index.html`，或在本地起一个静态服务器：

```bash
# Python
python3 -m http.server 8000
# 然后访问 http://localhost:8000
```
